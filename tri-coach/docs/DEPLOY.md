# פריסה ל-Vercel וחיבור ל-Intervals.icu

## חלק א׳ — פריסה ל-Vercel (כדי לפתוח בטלפון)

האפליקציה היא אתר סטטי (Vite). אין משתני סביבה ואין שרת.
> `main` בריפו עדיין לא מכיל את `tri-coach` — הקוד נמצא בענף `claude/epic-fermi-x3u9zc`. לכן יש להגדיר את הענף הזה כ-Production (אפשרות א׳) או לפרוס ישירות מהמחשב (אפשרות ב׳).

### אפשרות א׳ — דרך האתר (הכי פשוט, פריסה אוטומטית בכל push)
1. היכנס ל-[vercel.com](https://vercel.com) עם GitHub ← **Add New… → Project** ← בחר את הריפו `energy-brunch-2026`.
2. הגדרות:
   - **Root Directory:** `tri-coach`
   - **Framework Preset:** Vite (מזוהה אוטומטית; `vercel.json` כבר מגדיר build ו-output)
3. לחץ **Deploy**. אחרי שהפריסה הראשונה מסתיימת: **Settings → Git → Production Branch** ← `claude/epic-fermi-x3u9zc` ← שמור, ואז **Deployments → ⋯ → Redeploy**.
4. פתח את כתובת ה-**Production** (`https://<project>.vercel.app`) בטלפון.
   כתובות Preview מוגנות כברירת מחדל ב-Vercel Authentication — אל תשתמש בהן בטלפון (או כבה את ההגנה ב-Settings → Deployment Protection).

### אפשרות ב׳ — מהמחשב (CLI)
```bash
cd tri-coach
npx vercel          # התחברות ויצירת הפרויקט (פעם ראשונה; Root = התיקייה הנוכחית)
npx vercel --prod   # פריסת Production
```

### התקנה על הטלפון
- **iPhone (Safari):** שתף ← "הוסף למסך הבית".
- **Android (Chrome):** תפריט ⋮ ← "התקן אפליקציה".

### חשוב
- בטלפון הנתונים מתחילים ריקים (האחסון קשור לדפדפן ולכתובת). להעברה: במכשיר הישן הגדרות ← **ייצוא JSON**, בטלפון הגדרות ← **ייבוא JSON**. **מפתח ה-API לא מיוצא בכוונה** — מזינים אותו מחדש בכל מכשיר.
- אין צורך להגדיר CORS: Intervals.icu מאפשר קריאות ישירות מהדפדפן (נבדק).

## חלק ב׳ — חיבור Intervals.icu ו-Garmin ב-3 צעדים

1. **חשבון ומפתח.** פתח חשבון חינמי ב-[intervals.icu](https://intervals.icu). ה-**Athlete ID** (נראה כמו `i12345`) מופיע ב-URL אחרי כניסה (`intervals.icu/athlete/i12345/…`) וגם בהגדרות. ה-**API Key** נמצא בעמוד ההגדרות (`intervals.icu/settings`, אזור ה-API/Developer; אפשר ליצור שם מפתח חדש).
2. **חיבור Garmin ל-Intervals.icu.** באותו עמוד Settings, באזור **Garmin**, התחבר ל-Garmin ואשר: הורדת פעילויות, הורדת מדדי התאוששות (resting HR / HRV), והעלאת אימונים מתוכננים ל-Garmin Connect. חבר **ישירות** ל-Garmin ולא דרך Strava (Strava לא מחזיר נתוני פעילות ל-API). הגדר גם דופק מרבי ב-Intervals — יעדי הדופק באימוני האופניים הם באחוזים ממנו.
3. **חיבור באפליקציה.** הגדרות ← "סנכרון אוטומטי לשעון" ← הדבק Athlete ID ו-API Key ← **חבר ובדוק**. בעת החיבור (ובכפתור **בדיקת אימונים**) האפליקציה יוצרת אימון בדיקה אמיתי מכל ענף (שחייה, אופניים, ריצה) בעוד 45 יום, קוראת אותו חזרה, מדווחת אם הפורמט פוענח ואם המזהה נשמר ואם Garmin דיווח שגיאה, ומוחקת אותו. אם המזהה לא נשמר — הדחיפה נחסמת כדי לא ליצור כפילויות.

### איך זה עובד
- בכל פתיחה של האפליקציה (ובחזרה אליה, עד פעם ב-15 דקות): נמשכות פעילויות 28 הימים האחרונים ומדדי התאוששות; פעילות שתואמת אימון מתוכנן (אותו יום ואותו ענף) נרשמת אוטומטית, כולל משך, מרחק, דופק ו-RPE אם הוזן ב-Intervals; ההתאמה רצה; ואז 14 הימים הקרובים נדחפים ללוח השנה של Intervals.icu → Garmin Connect → השעון.
- אימונים שהתוכנית שינתה מתעדכנים ביומן; אימונים שהוסרו נמחקים. נוגעים **רק** באירועים שהאפליקציה יצרה (`external_id` שמתחיל ב-`tricoach:`) ומהיום והלאה.
- סימני עייפות (דופק מנוחה +7 ב-2 מתוך 3 ימים, או HRV נמוך ב-20% שלושה ימים) מורידים אימון קשה של היום/מחר לקל. נדרשים לפחות 7 ימי נתונים.

### מגבלות
- אפליקציית אינטרנט לא יכולה להסתנכרן ברקע כשהיא סגורה. השעון כבר מחזיק את האימונים של 14 הימים הקרובים; שינויים מהתאמה מגיעים אליו אחרי הפתיחה הבאה של האפליקציה.
- בלי RPE ב-Intervals, ההתאמה פועלת לפי ציות (משך) בלבד. אפשר להוסיף RPE באפליקציה: מסך שבוע ← האימון ← "עדכן רישום".
- אימון Brick נדחף כשני אימונים (אופניים וריצה). מים פתוחים מוגדרים כשחייה רגילה.
- Garmin עשוי להציג שמות באנגלית (שם האימון נבנה מענף+משך+עצימות); הכותרת העברית נמצאת בתיאור האימון ב-Intervals.icu.
- המפתח נשמר ב-IndexedDB של הדפדפן, לא מוצפן. מי שיש לו גישה למכשיר יכול לקרוא אותו; ניתן לבטל/להחליף מפתח בהגדרות Intervals.icu בכל עת.
